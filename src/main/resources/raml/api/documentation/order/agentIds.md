An Order is not attached for every state to the Agent. These Orders will not be included in the response.<br/>
Orders with the state PENDING, SCHEDULED, INPROGRESS, RUNNING and BLOCKED are attached to an Agent.    
For Orders with the status WAITING, whether they are attached to an Agent depends on the waiting reason.
